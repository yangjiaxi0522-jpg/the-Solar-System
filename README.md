# 探索太阳系 / Explore the Solar System

An interactive bilingual (English / 中文) learning prototype about the Solar System,
built for 8–10 year olds and designed to be used in a classroom.

**Live site:** https://YOUR-USERNAME.github.io/solar-system/

## What is in this repository

| File / folder | What it is |
|---|---|
| `index.html` `art.js` `script.js` `styles.css` | The site itself: HTML + CSS + vanilla JavaScript, no framework, no third-party images. All illustrations (planets, the guide, icons, the orbit map) are drawn in code; the science data comes from public NASA figures. |
| `about/` | The four prototype screenshots used on the “About & Theory” page. |
| `voice/` | The guide's recorded line on the home page. |
| `single-file.html` | The same site as one self-contained file (CSS, JS, screenshots and audio inlined) — handy for uploading to a VLE or sending to someone. |
| `design-notes.md` | Design notes mapping every design decision to the Lesson 1–3 theory, with the measured evidence. |

## How to open it

Open the live site above, or just open `index.html` in a browser.
Add `?lang=zh` to the URL for the Chinese interface (`?lang=zh#about` jumps straight to the portfolio page).

## Classroom use in one minute

1. Home — a real-data animation of the eight planets orbiting the Sun; tap any planet.
2. Pre-training — four word cards (star, planet, orbit, moon) before any content.
3. Modules — the Sun and the eight planets in one row; tap a body for its card.
4. Practice — drag the planets onto their orbits, explain why Earth suits life, then a short quiz.
5. Summary — recall the planets from the picture, tap to check, then a self-check list.

Every screen is keyboard reachable, every narration has a visible alternative, and the whole
prototype is one screen per section at 1440 × 900.
